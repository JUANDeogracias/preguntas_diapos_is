# Source Grounding

## Purpose

Ensure every academic question is supported by the official source
document:

docs/source/TEMA_2.pdf

## Instructions

Before generating questions:

1. Read the relevant pages from TEMA_2.pdf.
2. Extract the exact concepts being tested.
3. Preserve terminology from the document.
4. Do not introduce external facts.
5. Record the source page in each generated question.

If information cannot be verified from the source:

DO NOT create the question.

## Important

Do not rely exclusively on previous generated questions.

Always return to the PDF when creating new question sets.

The PDF is the source of truth.
