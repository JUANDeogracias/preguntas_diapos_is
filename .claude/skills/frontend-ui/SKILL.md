# Frontend UI

Build a professional educational web application.

## Visual goals

- dark interface
- clean typography
- large readable question text
- minimal distractions
- clear visual hierarchy
- desktop and mobile responsive
- smooth transitions
- accessible contrast

## Quiz screen

Must clearly show:

- question number
- progress
- question
- available options
- selected option
- submit/check action
- feedback when appropriate
- next-question action

Do not reveal the correct answer visually before submission.

## Feedback

After answering in Practice mode:

Correct answer:
show positive feedback.

Incorrect answer:
show selected answer,
correct answer,
and explanation.

## Exam mode

Never show correctness or explanations before the exam is finished.
