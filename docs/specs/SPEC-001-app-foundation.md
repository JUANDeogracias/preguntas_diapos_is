# SPEC-001 Application Foundation

## Goal

Create the initial React application for studying Ingeniería del
Software Tema 2.

## Requirements

The home screen must provide:

- Continue studying
- Random quiz
- Study by topic
- Mistakes
- Exam mode
- Statistics

## Quiz modes

### Practice

- immediate feedback
- explanations
- next question

### Exam

User selects:

- 10 questions
- 20 questions
- 30 questions
- 50 questions

Answers are evaluated only at the end.

### Topic

Allow selection among:

1. Ciclo de Vida
2. Paradigmas
3. Modelos Tradicionales
4. Proceso Unificado
5. Métodos Ágiles
6. DevOps

### Mistakes

Only questions previously answered incorrectly.

## Persistence

Use localStorage.

## Out of scope

- accounts
- backend
- database server
- cloud synchronization
